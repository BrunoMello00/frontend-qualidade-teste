Debug de Permissões do Sistema

Abra o console do navegador (F12) e execute:

// Para testar as permissões do usuário logado:
const auth = angular.injector(['ng']).get('AuthService');
console.log('Usuario atual:', auth.getCurrentUser());
console.log('É OWNER?', auth.isOwner());
console.log('Pode gerenciar vendas?', auth.canManageSales());
console.log('Permissões:', auth.permissions$.value);

Ou acesse: http://localhost:4200

Faça login como: owner@sistema.com / password

E teste se o menu de vendas aparece e se consegue criar vendas.
